# Personal Blog – shionxva

Welcome to my personal blog repository! This project is a fast, minimalist blog built using **Astro** and styled with the beautiful [**🍥Fuwari**](https://github.com/saicaca/fuwari) template.

---

## ✨ Features

- [x] Built with [Astro](https://astro.build) and [Tailwind CSS](https://tailwindcss.com)
- [x] Smooth animations and page transitions
- [x] Light / dark mode
- [x] Customizable theme colors & banner
- [x] Responsive design
- [x] Search functionality with [Pagefind](https://pagefind.app/)
- [x] [Markdown extended features](https://github.com/saicaca/fuwari?tab=readme-ov-file#-markdown-extended-syntax)
- [x] Table of contents
- [x] RSS feed

---

## Tech Stack

* **Framework:** Astro
* **Template:** Fuwari
* **Styling:** Tailwind CSS (via template)
* **Content:** Markdown / MDX

---


## Writing a Blog Post

Run pnpm `new-post <filename>` to create a new post and edit it in `src/content/posts/`

## Recreate

You can recreate the same website easily!

Visit the official [Fuwari repository](https://github.com/saicaca/fuwari) and follow their [README](https://github.com/saicaca/fuwari/blob/main/README.md) instruction.
